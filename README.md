# Student Management System

A console-based Student Management System developed using Core Java and Object-Oriented Programming concepts.

## 📌 About the Project

The Student Management System is a console-based Java application designed to manage student records efficiently.

The application allows users to add, view, search, update, and delete student records. It also validates student marks and calculates grades based on the marks entered.

The project is designed using separate classes for student data, business logic, and user interaction to keep the application simple, organized, and easy to maintain.

## ✨ Features

- Add a new student
- View all students
- Search student by ID
- Update student details
- Delete student records
- Validate marks between 0 and 100
- Automatically calculate student grades
- Prevent duplicate student IDs
- Handle invalid user input
- Simple menu-driven console interface

## 🛠 Technologies Used

- Java
- Core Java
- Object-Oriented Programming (OOP)
- ArrayList
- Collections
- Scanner
- Exception Handling
